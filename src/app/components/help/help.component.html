Manual de uso – InvoiceSync

Guía rápida y clara para usar la aplicación.

¿Qué es la automatización?

Es un proceso que, cada cierto tiempo, revisa tus correos, busca facturas y las procesa automáticamente. Puedes activarlo o detenerlo desde el panel principal con los botones de “Automatización”.

  • Funciona en “bucle”: se ejecuta cada cierto número de minutos.
  • Si estás subiendo un archivo manual, la app espera su turno: no se molestan entre sí.
¿Cómo subo facturas manualmente (PDF o XML)?

En el menú de navegación elige “Subir PDF” o “Subir XML”. Selecciona el archivo y confirma.

  • PDF: la app “lee” el documento con ayuda de inteligencia artificial.
  • XML (factura electrónica): se entiende de forma nativa; si es un XML distinto, igualmente se intentará procesar.
  • Las cargas manuales se encolan: verás el resultado cuando termine.
Indicadores y alertas
  • OpenAI (menú superior): “Sí” (verde) significa que la inteligencia artificial está disponible; “No” (rojo), que no lo está.
  • Tras cada proceso, verás un mensaje indicando si salió bien o si hubo algún problema.
Panel principal: ¿qué significa cada parte?
  • Acciones: botón para procesar correos ahora y accesos a gestión de Excel y cargas manuales.
  • Resultado del Proceso: el último resultado (éxito o error) con un resumen claro.
  • Archivos Excel Mensuales: listado de archivos generados por mes, con botón de descarga.
  • Resumen superior (tarjetas):
    • Archivos Excel: cuántos Excel se han generado.
    • Cuentas de Correo: cuántas casillas están configuradas y si están listas.
    • Automatización: si está encendida o apagada.
Excel: descargar y usar
  • Puedes descargar cualquier Excel: la descarga no cambia el archivo del servidor.
  • Los valores se guardan como números (puedes hacer fórmulas). Moneda local sin decimales; otras monedas con 2 decimales.
  • Si una factura llega mejorada (por ejemplo, con un código válido), el sistema conserva la versión correcta automáticamente.
Consejos rápidos
  • Si OpenAI está en “No”, aún puedes procesar XML; los PDF pueden requerir reintento cuando esté en “Sí”.
  • No hace falta detener la automatización para subir archivos manualmente: la app los ordena y procesa de a uno.
